Project Snapshot

Every memory deserves a storybook ending.

Barbie Storybook is a mobile AR scene builder where users place a Barbie stage, add worlds and props, use Glimmer for ideas, then save the moment as a storybook memory. The project moves from idea, to prototype, to deployment-ready build through a playful UI system that treats AR as a narrative surface instead of a one-off demo.

Keep Capture the AR moment and save a storybook memory.

User Journey

From first tap to saved memory.

The journey is strongest when it feels like play, not like technical setup. The deck frames the interaction as a five-step loop: open, launch AR, scan, build, capture.

Entry experience

The final home-screen direction puts brand first, action second. Large calls to action, fewer choices, and visible destinations make the product feel softer and clearer before scanning even begins.

AR proof

The progress build demonstrates a complete XR loop: home and onboarding, Needle Go AR launch, surface scan and anchor stage, world and props panels, Glimmer helper UI, and saved page flow.

XR Proof

The app runs as a real AR experience.

Interface System

Codeable component language.

The UI polish comes from a reusable set of cards, chips, buttons, inputs, panels, and icons. This page mirrors the app’s own `Outfit` + `Space Grotesk` pairing and pink, blush, gold palette.

Cards and panels

The library uses large rounded cards, soft highlights, light borders, and clear action buttons so the interface reads like a premium toy catalog.

HUD controls

The HUD keeps scan, book, narrator, and capture actions in one compact surface. It is built to feel codeable and reusable rather than one-off ornamental chrome.

Glimmer helper

Glimmer gives ideas and narration inside the flow. The helper layer is what turns a scene builder into a story-making product.

Asset System

High-fidelity assets support the build.

The final visual polish comes from combining UI assets, 3D props, book textures, and generated world backdrops in a reusable production pipeline.
