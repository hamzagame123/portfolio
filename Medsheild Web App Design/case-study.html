Key Design Decisions

Desktop-First Approach

Research showed 95% of tasks happen on desktop. We prioritized the primary use case instead of forcing mobile-first.

Logo-Driven Design System

The Medsheild logo informed the entire color palette, creating instant brand cohesion with the primary blue (#0066CC).

Cards as Primary Container

All content uses consistent card patterns with subtle shadows, creating visual hierarchy without clutter.

Simplified Scope

Focused on patient info and appointments. Intentionally excluded billing and clinical notes to reduce complexity.

DESIGN CHALLENGES

UX Obstacles & Solutions

Key design challenges and how I addressed them

01

Information Overload

Challenge

Medical data is complex. Too much information on screen creates cognitive overload.

Design Solution

Cards with clear hierarchy, progressive disclosure, and generous whitespace. Dashboard shows only what's needed now.

02

Scheduling Complexity

Challenge

Multiple chiropractors, various appointment types, and time conflicts create booking complexity.

Design Solution

Visual time slot grid with color-coded status badges, chiropractor filters, and clear "available" indicators.

03

Trust & Professionalism

Challenge

Healthcare software needs to feel secure and professional without being cold or clinical.

Design Solution

Logo-derived blue palette, soft shadows, generous spacing. Modern SaaS aesthetic that builds trust.

Key Learnings

Logo-Driven Design Works

Deriving colors from the existing logo created instant brand cohesion and gave the project strong visual identity from day one.

Desktop-First Can Be Valid

For B2B applications with known usage patterns, desktop-first is appropriate. Don't force mobile-first if it doesn't fit the use case.

Scope Discipline is Critical

Removing billing and clinical notes allowed focus on core functionality. Better to do less, well.

Mock Data Quality Matters

Realistic mock data made the app feel complete, improved testing, and helped identify edge cases early.

Reflection

This project taught me that professional aesthetics signal quality. In healthcare, trust is paramount, and the visual design directly impacts perceived reliability. The same functionality in a polished interface is perceived as more trustworthy than in basic UI.

If I were to start over, I would involve users even earlier. While I iterated based on research and design principles, formal usability testing with actual clinic staff would have validated decisions with real evidence.
